# FrameScope 2.1.2 · 视频质检

- 问题详情旁新增“循环回看”，以点击时的播放头为中心，循环播放前后各1秒。循环范围固定，靠近片头片尾自动限制在视频范围内。
- 再次点击按钮或按空格停止并暂停；自定义播放快捷键后，循环时空格仍可停止。定位、逐帧、切换视频和清空列表会结束循环。
- “设置”左侧新增“帮助”，集中说明添加视频、检测参数、播放定位、循环回看、逐帧、复核排序、黑边忽略、监视器、导出、快捷键和更新。
- 队列下方及问题区底部的说明文字移至帮助，释放工作区空间。当前视频的解码提示保留在帮助与顶部信息框中。
- 同时包含2.1.1的双击提前1秒、复核后推进到下一项、窄列表排版和顶部信息框改进。

可在软件内检查更新，或运行完整安装包覆盖升级，无需卸载。
