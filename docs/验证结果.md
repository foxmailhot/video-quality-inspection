## 检测核心

使用自制 H.264 合成视频（320×192、25 fps、150 帧）验证：

| 注入异常 | 预期位置 | 结果 |
|---|---|---|
| 单帧黑屏 | 第 20 帧，0.800 秒 | 检出，区间 0.800–0.840 秒 |
| 连续定帧 | 第 50–84 帧 | 检出，区间 2.000–3.400 秒 |
| 单帧白闪 / 夹帧 | 第 110 帧，4.400 秒 | 检出，区间 4.400–4.440 秒 |
| 突发随机噪声 | 第 125–127 帧 | 检出疑似花屏，区间 5.000–5.120 秒 |

孤立黑帧也符合“短暂夹入后返回”条件，因此同一位置同时有黑帧与夹帧两个标签；上述视频共 5 个标记。CPU 与 GPU 的问题类型及帧区间一致，数值统计允许解码路径导致的细微差别。

另已通过：正常单向切镜头不触发夹帧；最少连续黑帧阈值为 2 时忽略单帧黑屏；片尾黑场与定帧正确收尾；可变帧率黑帧按真实 0.400 秒时间戳定位；主动取消；无效文件报错。

1920×1080 原始分辨率、60 帧额外样本通过黑帧与定帧检查，本次 GPU 扫描耗时约 1.75 秒。该小规模合成测试不代表长片或所有编码的吞吐量。
