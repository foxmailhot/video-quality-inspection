# FrameScope 2.1.1

- 双击问题定位到起点前1秒；不足1秒时定位到视频开头，暂停并显示该位置的实际画面。
- 复核后选中原列表中的下一个非误报问题，不再跟随被移到末尾的误报项。没有后续问题时选择附近仍可复核的问题，无可选项时清空选择。
- 默认按时间排列，误报置底；手动表头排序继续生效，刷新时保留所选问题和滚动位置。
- 问题表格固定行高，长依据省略显示，完整内容保留在悬停提示和下方详情；窄窗口下横向滚动，避免依据逐字换行撑满整个列表。
- 状态与队列信息合并到检测参数右侧的信息框，取消底部状态行，将空间留给工作区。
- 保留2.1.0夹帧检测、黑边全局忽略及播放头拖拽功能。
