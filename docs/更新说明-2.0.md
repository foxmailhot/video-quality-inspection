# FrameScope 2.0（2026-10-10）

启动后台检查 GitHub 视频质检仓库的最新正式 Releases；同版或旧版不弹窗，新版询问是否下载。顶部“更新”可手动检查。下载不阻塞预览，可取消；分片和完整安装包均校验 SHA256 和大小。下载后询问是否保存设置、停止任务并关闭软件启动覆盖安装，也可稍后安装。下载失败不会运行不完整文件。

首次从 1.5 升级至 2.0 需要使用完整安装包，1.5 本身没有自动更新功能。

发行版附件包含安装包、latest.json 更新记录和 SHA256 校验文件。更新程序使用固定仓库编号识别站点，仓库改名后仍可查找，不内置账号或令牌。
