# 视频质检 / FrameScope

Windows 本地视频质量检查软件。安装包包含 Python、Qt、FFmpeg 与 NVIDIA CUDA 运行库，不需要另外安装开发环境。视频和检测日志留在本机。

## 安装

在本仓库 **Releases** 页面下载最新 `FrameScope-版本-Setup-x64.exe`。支持新安装或覆盖升级，原设置和检测记录保留。从 1.5 首次升级到 2.0 需要运行完整安装包。

## 检查工作台

黑帧、定帧、夹帧、花屏、四边黑边与镜像候选检测；独立显卡分析及 CPU 回退；队列、逐帧按钮与滚轮、快捷键、可拖动工作区、白底监视器；人工确认与误报隐藏；问题编辑、表头双击排序、HTML 单帧截图日志。

## 2.0 自动更新

启动后在后台访问本仓库的最新正式 Releases。当前或旧版本不弹窗；新版本询问是否下载，下载完成验证大小与 SHA256，再询问是否保存、关闭软件并启动覆盖安装。可取消下载或稍后安装。仓库改名后仍通过固定仓库编号识别。网络错误不影响本地视频检查。

## 源码与发行

源码位于 `source/`，使用说明位于 `docs/`。安装 `source/requirements.txt` 后运行 `python source/app.py`。

Windows 自动构建流程位于 `.github/workflows/release.yml`。更新 `publish.json` 的版本和说明并提交后，流程构建完整安装包，在发布前验证附件大小和 SHA256，最后公开正式发行版。新增版本时也需要更新 `source/updater.py` 的版本、版本资源和安装脚本。已发布版本不会被自动覆盖。

检测结果是候选问题，需要人工复核。验证记录见 `docs/验证结果.md`。

## 2.0.1 布局调整

快捷键、背景、更新收进“设置”；检测进度位于监视器上方；本地处理、开始队列、停止位于播放轨道与问题工作区之间。
